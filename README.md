# Landing Google Ads — Nettoyage de Toiture (Tonio Rénov')

Modèle de landing page réutilisable pour campagnes Google Ads d'artisans.
Contenu réel actuel : Tonio Rénov' — démoussage/entretien de toiture, Bayonne & Côte Basque.

## Réutiliser pour un autre métier
Dupliquer `index.html`, changer :
- Textes hero / étapes / FAQ / form (en dur dans le HTML)
- Bloc `CONFIG` en bas de fichier (avis, FAQ)
- Couleur d'accent `--tuile-*` dans `<style>` si besoin
- Photo `roof.jpg`

## Stack
HTML/CSS/JS statique, aucune dépendance de build. Déployable tel quel sur Vercel.
